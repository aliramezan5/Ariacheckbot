# داشبورد استعلام صیادی پاسارگاد

یک وب‌اپ راست‌به‌چپ و سازگار با آیفون برای خواندن فایل Excel چک‌ها، تأیید شناسه‌های دارنده، تلاش برای استعلام زنده از endpoint پاسارگاد و ساخت خروجی ممیزی‌پذیر Excel.

## اجرا

```bash
npm install
npm run dev
```

## نکات امنیتی

- فایل و پاسخ‌ها در مرورگر پردازش می‌شوند و توکن، کوکی یا پاسخ خام بانک در `localStorage` ذخیره نمی‌شود.
- مقدار مانده‌ای که از بانک دریافت نشده، صفر نمی‌شود و در خروجی خالی می‌ماند.
- استعلام فقط بعد از تأیید دستی کد ملی دارنده انجام می‌شود.
- GitHub Pages استاتیک است. اگر endpoint بانک CORS یا ورود مرورگر بخواهد، استعلام زنده در مرورگر متوقف می‌شود و باید از اسکریپت Python/Pyto یا یک backend امن استفاده شود.

## انتشار در مخزن موجود

Workflow سطح بالاتر، پوشهٔ `pages` را با `npm ci` و `npm run build` می‌سازد و artifact را با GitHub Pages منتشر می‌کند (از بخش Actions به‌صورت دستی اجرا می‌شود). Worker ریشهٔ مخزن مستقل می‌ماند.

برای نمایش فوریِ همین build، در مسیر `Settings → Pages → Build and deployment` می‌توان Source را روی `Deploy from a branch`، Branch را روی `main` و Folder را روی `/docs` گذاشت. برای build خودکار، Source را روی `GitHub Actions` بگذارید و Workflow را از بخش Actions دستی اجرا کنید. اگر اولین اجرا با پیام `Resource not accessible by integration` متوقف شد، همین انتخاب Source در Settings را یک‌بار انجام دهید و Workflow را دوباره اجرا کنید.
