# محاسبه مبلغ چک

وب‌اپ موبایلی محاسبه اقساط مساوی با کاهش مانده و سود مرکب ماهانه.

## نرخ کارمزد
- حالت اتومات: نرخ پایه سرمایه شخصی ۷٪ و سرمایه‌گذار ۵٪ در ماه.
- حالت دستی: نرخ ماهانه توسط کاربر وارد می‌شود.
- قواعد اختیاری رأس و مبلغ از تنظیمات قابل تعریف و ذخیره هستند.

## امکانات
- تم روز و شب
- تنظیم اندازه فونت و اندازه رابط
- تشخیص خودکار مدت معامله و رأس چک‌ها
- ذخیره تنظیمات روی دستگاه
