# محاسبه مبلغ چک

وب‌اپ موبایلی برای محاسبه اقساط مساوی بر مبنای کاهش مانده و سود مرکب ماهانه ۷٪.

## ورودی‌ها
- مانده نقدی معامله (میلیون تومان)
- تعداد چک‌ها
- فاصله بین هر چک (ماه)

## فرمول
نرخ دوره: `i = (1 + 0.07)^k - 1`

قسط مساوی: `A = P × i / (1 - (1 + i)^(-n))`
